# Mac em ASCII, janelas em escadinha e pet com teletransporte — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um Macintosh gigante em ASCII vivo atrás das janelas da mesa, as janelas da direita numa escadinha sem sobreposição e, na home, o pet do canto entrando e saindo com um teletransporte quando o SOUZXXX cobre a mesa.

**Architecture:** O Mac ASCII é um canvas 2D atrás das janelas (`-z-10` dentro da `section.mesa`, que já é `isolate`). A lógica fica em módulos puros e testáveis em `components/mesa-ascii/`: grade de células, ondas, silhueta, âncora e cena. Um componente de cliente fino só mede, pinta e ouve o mouse. As janelas viram uma coluna flex com uma faixa elástica no meio. O teletransporte é uma tabela de keyframes pura (`components/pet/teleporte.ts`) tocada pela Web Animations API num hook. Inverter no meio do caminho é só trocar o sinal do `playbackRate`.

**Tech Stack:** Next 14 App Router, React 18, Tailwind 3, Canvas 2D, Web Animations API, `node:test` via `tsx --test`, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-28-mac-ascii-design.md`. Protótipo aprovado: `docs/superpowers/specs/2026-10-28-mac-ascii-prototipo.html`, função `cenaMosaico`. Print de referência: `docs/superpowers/specs/2026-10-28-mac-ascii-print-referencia.png`.

## Global Constraints

- Cores: creme `#F5F3EE` e carvão `#1C1A17`. O dourado `#D4A017` só aparece no selo `*` do gabinete; dourado nunca toca creme.
- Nenhuma dependência nova no `package.json`.
- Mac ASCII só com `(min-width: 1024px)`; abaixo disso nada monta. Celular sem nenhuma mudança.
- Grade de 9×11 px CSS por célula; DPR do canvas limitado a 2.
- Fonte do canvas: `600 10px ui-monospace, SFMono-Regular, Menlo, monospace`. **Não** `font-mono` (Courier Prime).
- `prefers-reduced-motion`: o Mac desenha um quadro parado, sem ondas nem pulo; o pet aparece e some sem animação.
- O pet só muda na home (`/` e `/en`); nas outras rotas fica idêntico a hoje.
- Comentários e nomes em português, no tom dos arquivos vizinhos (explicam o porquê).
- Componente de cliente nunca importa `dict` como valor (`import type` pode).
- Testes unitários: `npx tsx --test components/pet/*.test.ts components/mesa-ascii/*.test.ts`.
- Grafia da marca: souzxxx (três x).
- Branch `feat/mac-ascii`. Nada de merge nem push na `main` sem o OK do Leonardo. Não commitar o `tsconfig.tsbuildinfo`.
- **Execução multiagente:** os agentes não fazem `git commit`; o orquestrador commita por task. Cada agente só toca os arquivos da própria task.

```
altura = ALTURA_MAC * mesa.h
olhosW = (OLHOS_UV.dir.u1 - OLHOS_UV.esq.u0) * altura   // 0.20·Hm
olhosH = (OLHOS_UV.v1 - OLHOS_UV.v0) * altura            // 0.055·Hm
vaoX0 = leiame.x + leiame.w ; vaoX1 = render.x
se vaoX1 - vaoX0 >= olhosW + 2·FOLGA_OLHOS:
    ex = (vaoX0 + vaoX1) / 2 ; ey = render.y + 0.45·render.h      // rosto no vão LEIA-ME | RENDER
senão:                                                            // rosto na faixa RENDER / TERMINAL
    fy0 = render.y + render.h ; fy1 = terminal.y
    enquanto olhosH + 2·FOLGA_OLHOS > fy1 - fy0 e altura > ALTURA_MIN·mesa.h: altura *= 0.95 (recalcula olhosH)
    ex = (vaoX0 + max(render.x + render.w, terminal.x + terminal.w)) / 2 ; ey = (fy0 + fy1) / 2
cx    = ex - (centro u dos olhos = -0.05)·altura      →  ex + 0.05·altura
baseY = ey + (0.43 - centro v dos olhos = -0.245)·altura  →  ey + 0.675·altura
```
